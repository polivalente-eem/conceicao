# Portal de Estudos — Ensino Médio

Site estático com duas etapas:

1. `index.html` — seleção entre 1º, 2º e 3º ano.
2. `materias.html` — cards das disciplinas, filtrados pelo ano escolhido.

## Disciplinas
Matemática, Química, Biologia, Português, Geografia, História, Física, Inglês, Artes, Filosofia, Sociologia e Educação Física.

## Como configurar os Drives
Abra `script.js` e substitua cada `"#"` pelo link correspondente da pasta do Google Drive.

Exemplo:
`"matematica": "https://drive.google.com/drive/folders/SEU_LINK"`

É possível usar um Drive diferente para cada ano e disciplina.

## Publicação gratuita
O projeto pode ser publicado no GitHub Pages. Basta colocar os quatro arquivos no repositório e ativar Pages.

Os arquivos não dependem de servidor ou banco de dados.

## Identidade visual
A página inicial utiliza `logo.png` como marca d'água com baixa opacidade.
